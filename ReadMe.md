### Publications

**Data drift-resilient inference: Maintaining model integrity via novel lightweight distribution correction**  
Malçok, H., Bozkır, R., Cicioğlu, M. *Future Generation Computer Systems*, 184, 108598 (2026). [DOI](https://doi.org/10.1016/j.future.2026.108598)  
Model-agnostic, inference-time distribution correction that recovers performance lost to data drift at the data level, without retraining or touching the model. Improved F1 across multiple datasets while running faster and lighter than existing methods.
